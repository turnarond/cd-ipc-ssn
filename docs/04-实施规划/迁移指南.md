# SSN 迁移指南

**版本: 2.1.0**

## 从 v2.0 迁移到 v2.1

### 重大变更：统一命名到 ssn_ 前缀

v2.1 完成了从 `cd_ipc_`/`ipc_` 到 `ssn_` 的统一命名迁移。

### 类型重命名

| 旧类型 | 新类型 |
|--------|--------|
| `ipc_client_t` | `ssn_client_t` |
| `ipc_server_t` | `ssn_server_t` |
| `ipc_node_t` | `ssn_node_t` |
| `ipc_header_t` | `ssn_header_t` |
| `ipc_url_ref_t` | `ssn_url_ref_t` |
| `ipc_data_ref_t` | `ssn_data_ref_t` |
| `ipc_node_config_t` | `ssn_node_config_t` |
| `ipc_client_auto_t` | `ssn_client_auto_t` |
| `cli_id_t` | `ssn_peer_id_t` |

### 函数重命名

使用 `sed` 即可批量替换：

```bash
# 客户端 API
sed -i 's/ipc_client_/ssn_client_/g' *.c *.h

# 服务端 API
sed -i 's/ipc_server_/ssn_server_/g' *.c *.h

# 节点 API
sed -i 's/ipc_node_/ssn_node_/g' *.c *.h
```

### 宏重命名

| 旧宏 | 新宏 |
|------|------|
| `IPC_HEADER_SIZE` | `SSN_HEADER_SIZE` |
| `IPC_MAX_PACKET_SIZE` | `SSN_MAX_PACKET_SIZE` |
| `IPC_MSG_TYPE_*` | `SSN_MSG_TYPE_*` |
| `IPC_ERR_*` | `SSN_ECODE_*` |

### 头文件重命名

| 旧文件 | 新文件 |
|--------|--------|
| `cd_ipc_client.h` | `ssn_client.h` |
| `cd_ipc_server.h` | `ssn_server.h` |
| `cd_ipc_protocol.h` | `ssn_frame.h` |
| `cd_ipc_cliauto.h` | `ssn_cliauto.h` |
| `node/ipc_node.h` | `node/ssn_node.h` |

### API 签名变更

`ssn_node_subscribe` 新增 `peer_address` 参数：

```c
// v2.0
bool ssn_node_subscribe(ssn_node_t *node, const ssn_url_ref_t *url,
                        ssn_client_msg_handler_t callback, void *arg,
                        uint64_t timeout_ms);

// v2.1
bool ssn_node_subscribe(ssn_node_t *node, const char *peer_address,
                        const ssn_url_ref_t *url,
                        ssn_client_msg_handler_t callback, void *arg,
                        uint64_t timeout_ms);
```

### 地址格式变更

服务器地址现在需要明确的协议前缀：

```c
// v2.0: "127.0.0.1:8888" (被当作 Unix socket)
// v2.1: "tcp://127.0.0.1:8888" (明确指定 TCP)
```

### 保持不变的部分

- VSI 平台抽象层（`vsi/ipc_*`）保持 `ipc_` 前缀
- 内部 transport/protocol/util 模块（`ssn_*`）保持不变
- 库文件 `libssn_transport.so` 保持不变

## v2.1 → v2.2 迁移要点（2026-05-06）

- `ipc_client_auto_state_t` 枚举改名 `ssn_client_auto_state_t`
- `ssn_cliauto` 订阅改用 `ssn_client_subscribe`（替代 `ssn_client_message`）
- `ssn_client_connect` 返回类型由 `int` 修正为 `bool`
- `VSOA` 引用统一改名为 `SSN`（如 `VSOA_CLIENT_AUTO_MAX_PING_LOST` → `SSN_CLIENT_AUTO_MAX_PING_LOST`）

## v2.2 → v2.3 迁移要点（2026-05-07）

- 无公开 API 命名变更；本版本为架构升级（CollectionScheduler、DataPipeline、DeviceStateMachine、DiagnosticsCollector），涉及 driver-sdk 侧

## 从 v1.0 迁移到 v2.0

### 2.0 版本新功能

- 节点发现机制（组播发现、目录服务）
- QoS 服务质量框架
- 多协议支持（Unix Socket、TCP、UDP）
- 完整的示例代码和文档

### 向后兼容

v2.0 完全向后兼容 v1.0。所有 1.0 API 保持不变，现有代码无需修改即可运行。
