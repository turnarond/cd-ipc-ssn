# v3.0.0 C++17 多 Peer Node 实施计划

> **执行要求：** 必须按任务逐项实施并在任务边界评审。所有步骤使用复选框跟踪；未经维护者确认不得提交或推送。

**目标：** 建立唯一公开的 C++17 多 Peer Node API，支持原始双向消息、外部 poll、可选后台线程、无锁回调和有界背压，并删除未被外部使用的旧 Node C API。

**架构：** 公共 `ssn::Node` 使用 move-only PImpl；私有 `NodeImpl` 组合 Peer 表、命令/事件队列、发送队列和统一 `PollDriver`。现有 transport、frame、client/server C API 保持兼容，Node 所需的聚合轮询能力通过内部适配接口提供。

**内部接口的可见性口径（任务 4 落地时修正）：** `NodeBackend`/`PollDriver` 编入 `libssn_framework`，而非阻塞连接的 `ssn_transport_connect_begin_internal()`/`ssn_transport_connect_finish_internal()` 实现在 `libssn_transport`。`.so` 边界上，`C_VISIBILITY_PRESET hidden` 未导出的 C 符号无法跨库解析，因此这两个函数**显式声明 default 可见性以允许跨库链接**，但仍**不安装头文件、不进公共文档、不使用 `SSN_API` 宏**（区别于公开 C API）。`test/verify_exports.sh` 维护一份已知内部符号白名单，白名单外的新增内部符号视为回归。

**技术栈：** C99、C++17、CMake、POSIX/WSL、pthread、现有 SSN transport/frame/client/server、项目自有测试宏、ASan/UBSan/ThreadSanitizer。

**规格：** `docs/03-设计/方案设计/2026-09-14-C++17多Peer-Node设计.md`

## 全局约束

- Node 层只公开 C++17 API；其他公开 C API 的符号和行为保持兼容。
- 公共类采用 PImpl，不在公共布局暴露 STL 容器、锁、线程或 C 句柄。
- `Node` 不可复制、可以移动，析构函数 `noexcept`。
- 首版支持多个监听地址、多个入站/出站 Peer、原始单播和广播。
- 外部 `poll()` 与后台线程共用一个驱动实现，实例生命周期内不得混用。
- 用户回调无内部锁、同一 Node 串行有序，并允许安全调用非阻塞 API。
- 接收默认 `MessageView` 零拷贝且仅在回调期有效；发送在返回前复制。
- 运行时失败使用 `Status`/`Result<T>`，不得以异常作为正常控制流。
- 严格执行 TDD 红—绿—重构；Windows 工作区必须在 WSL 中构建和测试。
- 代理禁止直接 commit/push；维护者按阶段合并为少量完整提交。
