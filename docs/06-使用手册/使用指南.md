# SSN 使用指南

## 1. 概述

本指南旨在帮助用户快速上手 SSN 库，包括基本概念、核心功能和使用方法。SSN 是一个高性能的进程间通信库，支持 RPC、发布/订阅和消息传递，可通过 Unix Socket、TCP 和 UDP 协议进行通信。

## 2. 快速开始

### 2.1 环境要求

- CMake >= 3.12
- GCC >= 4.8 或 CLang >= 3.0
- POSIX 兼容系统 (Linux, macOS)

### 2.2 构建库

```bash
# 克隆仓库
git clone https://github.com/acoinfo/edge-framework.git
cd edge-framework/src/comms/SSN

# 构建库
mkdir build
cd build
cmake ..
make

# 安装库（可选）
sudo make install
```

### 2.3 第一个应用

```c
#include "ssn_client.h"
#include "ssn_server.h"
#include "version/ssn_version.h"

// 消息处理回调函数
static void message_handler(const ssn_data_ref_t *data, void *arg) {
    printf("Received message: %.*s\n", (int)data->length, (const char *)data->data);
}

int main(void) {
    // 打印版本信息
    printf("SSN version: %s\n", ssn_version_get_string());

    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/my_server", NULL);
    if (!server) {
        printf("Failed to create server\n");
        return 1;
    }

    // 启动服务器
    if (!ssn_server_start(server)) {
        printf("Failed to start server\n");
        ssn_server_destroy(server);
        return 1;
    }

    // 创建客户端
    ssn_client_t *client = ssn_client_create(message_handler, NULL);
    if (!client) {
        printf("Failed to create client\n");
        ssn_server_destroy(server);
        return 1;
    }

    // 连接服务器
    if (!ssn_client_connect(client, "unix:///tmp/my_server", NULL)) {
        printf("Failed to connect to server\n");
        ssn_client_close(client);
        ssn_server_destroy(server);
        return 1;
    }

    // 发送消息
    const char *message = "Hello, SSN!";
    ssn_data_ref_t data = {
        .data = (void *)message,
        .length = strlen(message)
    };
    ssn_client_message(client, &data);

    // 等待一段时间
    sleep(1);

    // 清理资源
    ssn_client_close(client);
    ssn_server_destroy(server);

    return 0;
}
```

## 3. 核心概念

### 3.1 传输协议

SSN 支持三种传输协议：

- **Unix Socket**：适用于本地进程间通信，速度最快
- **TCP**：适用于网络通信，提供可靠的面向连接传输
- **UDP**：适用于实时性要求高的场景，提供无连接的尽力而为传输

### 3.2 节点抽象

节点是 SSN 的核心概念，它提供了一个高级抽象，支持：

- 同时作为客户端和服务器
- 节点间通信
- 节点生命周期管理
- 服务发现（未来版本）

### 3.3 通信模式

SSN 支持三种通信模式：

- **消息传递**：直接发送消息给指定的目标
- **RPC**：远程过程调用，请求-响应模式
- **发布/订阅**：基于主题的消息发布和订阅

## 5. 使用示例

### 5.1 基础通信

**客户端代码**：

```c
#include "ssn_client.h"

static void message_handler(const ssn_data_ref_t *data, void *arg) {
    printf("Received message: %.*s\n", (int)data->length, (const char *)data->data);
}

int main(void) {
    // 创建客户端
    ssn_client_t *client = ssn_client_create(message_handler, NULL);
    if (!client) return 1;

    // 连接服务器
    if (!ssn_client_connect(client, "unix:///tmp/my_server", NULL)) {
        ssn_client_close(client);
        return 1;
    }

    // 发送消息
    const char *message = "Hello from client!";
    ssn_data_ref_t data = {
        .data = (void *)message,
        .length = strlen(message)
    };
    ssn_client_message(client, &data);

    // 等待响应
    sleep(2);

    // 清理
    ssn_client_close(client);
    return 0;
}
```

**服务器代码**：

```c
#include "ssn_server.h"

static void message_handler(const ssn_data_ref_t *data, ssn_server_client_t *client, void *arg) {
    printf("Received message from client: %.*s\n", (int)data->length, (const char *)data->data);

    // 回复客户端
    const char *response = "Hello from server!";
    ssn_data_ref_t response_data = {
        .data = (void *)response,
        .length = strlen(response)
    };
    ssn_server_client_send(client, &response_data);
}

int main(void) {
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/my_server", NULL);
    if (!server) return 1;

    // 设置消息处理回调
    ssn_server_set_message_handler(server, message_handler, NULL);

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 运行服务器
    printf("Server running. Press Ctrl+C to stop.\n");
    pause();

    // 清理
    ssn_server_destroy(server);
    return 0;
}
```

### 5.2 RPC 调用

**服务器代码**：

```c
#include "ssn_server.h"

static void add_handler(const ssn_data_ref_t *data, ssn_server_client_t *client, 
                       const ssn_url_ref_t *url, ssn_server_response_t *response, void *arg) {
    // 解析参数
    int a, b;
    sscanf((const char *)data->data, "%d %d", &a, &b);

    // 计算结果
    int result = a + b;

    // 构建响应
    char response_str[32];
    snprintf(response_str, sizeof(response_str), "%d", result);
    response->data.data = (void *)response_str;
    response->data.length = strlen(response_str);
    response->status = 0;
}

int main(void) {
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/rpc_server", NULL);
    if (!server) return 1;

    // 注册 RPC 方法
    ssn_server_add_rpc_method(server, "/math/add", add_handler, NULL);

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 运行服务器
    printf("RPC server running. Press Ctrl+C to stop.\n");
    pause();

    // 清理
    ssn_server_destroy(server);
    return 0;
}
```

**客户端代码**：

```c
#include "ssn_client.h"

static void rpc_reply_handler(int status, const ssn_data_ref_t *data, void *arg) {
    if (status == 0) {
        printf("RPC call succeeded, result: %.*s\n", (int)data->length, (const char *)data->data);
    } else {
        printf("RPC call failed with status: %d\n", status);
    }
}

int main(void) {
    // 创建客户端
    ssn_client_t *client = ssn_client_create(NULL, NULL);
    if (!client) return 1;

    // 连接服务器
    if (!ssn_client_connect(client, "unix:///tmp/rpc_server", NULL)) {
        ssn_client_close(client);
        return 1;
    }

    // 构建 RPC 请求
    const char *request = "5 3";
    ssn_data_ref_t data = {
        .data = (void *)request,
        .length = strlen(request)
    };

    // 构建 URL
    ssn_url_ref_t url = {
        .path = "/math/add",
        .query = NULL,
        .fragment = NULL
    };

    // 发起 RPC 调用
    int req_id = ssn_client_call(client, &url, &data, rpc_reply_handler, NULL, 1000);
    if (req_id < 0) {
        printf("Failed to send RPC call\n");
        ssn_client_close(client);
        return 1;
    }

    // 等待响应
    sleep(2);

    // 清理
    ssn_client_close(client);
    return 0;
}
```

### 5.3 发布/订阅

**发布者代码**：

```c
#include "ssn_server.h"

int main(void) {
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/pubsub_server", NULL);
    if (!server) return 1;

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 构建主题 URL
    ssn_url_ref_t url = {
        .path = "/news",
        .query = NULL,
        .fragment = NULL
    };

    // 发布消息
    for (int i = 0; i < 5; i++) {
        char message[64];
        snprintf(message, sizeof(message), "News update %d", i + 1);
        ssn_data_ref_t data = {
            .data = (void *)message,
            .length = strlen(message)
        };
        ssn_server_publish(server, &url, &data);
        printf("Published: %s\n", message);
        sleep(1);
    }

    // 清理
    ssn_server_destroy(server);
    return 0;
}
```

**订阅者代码**：

```c
#include "ssn_client.h"

static void message_handler(const ssn_data_ref_t *data, void *arg) {
    printf("Received on /news: %.*s\n", (int)data->length, (const char *)data->data);

int main(void) {
    // 创建客户端
    ssn_client_t *client = ssn_client_create(NULL, NULL);
    if (!client) return 1;

    // 连接服务器
    if (!ssn_client_connect(client, "unix:///tmp/pubsub_server", NULL)) {
        ssn_client_close(client);
        return 1;
    }

    // 构建主题 URL
    ssn_url_ref_t url = {
        .path = "/news",
        .query = NULL,
        .fragment = NULL
    };

    // 订阅主题
    int sub_id = ssn_client_subscribe(client, &url, message_handler, NULL, 1000);
    if (sub_id < 0) {
        printf("Failed to subscribe\n");
        ssn_client_close(client);
        return 1;
    }

    // 等待消息

    // 清理

    return 0;
}
```

## 8. 性能优化

### 8.1 连接管理

- **连接池**：对于频繁通信的场景，使用连接池复用连接
- **长连接**：使用长连接减少连接建立和销毁的开销
- **心跳机制**：定期发送心跳消息保持连接活跃

### 8.2 消息处理

- **批量发送**：将多个小消息合并为一个大消息发送
- **消息压缩**：对大消息进行压缩传输
- **异步处理**：使用异步 API 避免阻塞主线程

### 8.3 内存管理

- **内存池**：预分配内存池减少内存分配开销
- **零拷贝**：使用零拷贝技术减少数据复制
- **大消息分片**：对超过 128KB 的消息进行分片传输

## 9. 常见问题

### 9.1 连接失败

**问题**：客户端无法连接到服务器

**解决方案**：
- 检查服务器是否正在运行
- 检查地址格式是否正确（例如：`unix:///tmp/server`）
- 检查权限是否正确
- 检查防火墙设置

### 9.2 RPC 调用超时

**问题**：RPC 调用超时

**解决方案**：
- 检查网络连接是否稳定
- 增加超时时间
- 检查服务器是否正常处理请求
- 检查请求数据是否正确

### 9.3 消息丢失

**问题**：发布的消息没有被订阅者收到

**解决方案**：
- 检查订阅是否成功
- 检查主题路径是否正确
- 检查网络连接是否稳定
- 对于关键消息，考虑使用 RPC 而不是发布/订阅

### 9.4 性能问题

**问题**：通信性能不达标

**解决方案**：
- 使用 Unix Socket 进行本地通信
- 优化消息大小
- 使用批量发送
- 调整缓冲区大小
- 使用多线程处理消息

## 10. 进阶功能

### 10.1 多线程通信

SSN 是线程安全的，可以在多线程环境中使用：

```c
// 在主线程中创建客户端
ssn_client_t *client = ssn_client_create(message_handler, NULL);

// 在子线程中发送消息
void *send_thread(void *arg) {
    ssn_client_t *client = (ssn_client_t *)arg;
    // 发送消息...
    return NULL;
}

pthread_t thread;
pthread_create(&thread, NULL, send_thread, client);
```

### 10.2 传输协议选择

根据不同的场景选择合适的传输协议：

- **Unix Socket**：本地进程间通信，速度最快
- **TCP**：网络通信，提供可靠传输
- **UDP**：实时性要求高的场景，如音频、视频流

### 10.3 安全通信

未来版本将支持 TLS/DTLS 加密传输，当前版本可以在应用层实现加密：

```c
// 加密消息
uint8_t encrypted_data[1024];
size_t encrypted_len = encrypt(data, len, encrypted_data, sizeof(encrypted_data));

// 发送加密消息
ssn_data_ref_t encrypted_msg = {
    .data = encrypted_data,
    .length = encrypted_len
};
ssn_client_message(client, &encrypted_msg);

// 接收方解密
uint8_t decrypted_data[1024];
size_t decrypted_len = decrypt(encrypted_msg.data, encrypted_msg.len, 
                              decrypted_data, sizeof(decrypted_data));
```
