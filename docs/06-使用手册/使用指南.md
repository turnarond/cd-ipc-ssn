## 1. 概述

本指南旨在帮助用户快速上手 SSN 库，包括基本概念、核心功能和使用方法。SSN 是一个高性能的进程间通信库，支持 RPC、发布/订阅和消息传递，可通过 Unix Socket、TCP 和 UDP 协议进行通信。本指南所有 API 签名均与当前版本（v2.5.0）头文件一致。

## 2. 快速开始

### 2.1 环境要求

- CMake >= 3.12
- GCC >= 4.8 或 CLang >= 3.0
- POSIX 兼容系统 (Linux, macOS)

### 2.2 构建库

```bash
# 克隆仓库
git clone https://github.com/acoinfo/cd-ipc-ssn.git
cd cd-ipc-ssn

# 构建库
mkdir build
cd build
cmake ..
make

# 安装库（可选）
sudo make install
```

### 2.3 第一个应用

```c
#include <pthread.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

#include "ssn_client.h"
#include "ssn_server.h"
#include "version/ssn_version.h"

// 服务器事件循环线程：轮询驱动连接与消息处理
// （事件循环需自行驱动，实际应用中需持续轮询，见 5.1 服务器示例）
static void *server_loop(void *arg)
{
    ssn_server_t *server = (ssn_server_t *)arg;
    int elapsed = 0;
    while (elapsed < 10) {           // poll 100ms + sleep 1s，共运行 10 秒
        ssn_server_poll(server, 100);
        sleep(1);
        elapsed++;
    }
    return NULL;
}

int main(void)
{
    // 打印版本信息
    printf("SSN version: %s\n", ssn_version_get_string());

    // 创建并启动服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/my_server");
    if (!server) {
        printf("Failed to create server\n");
        return 1;
    }
    if (!ssn_server_start(server)) {
        printf("Failed to start server\n");
        ssn_server_destroy(server);
        return 1;
    }

    // 启动服务器事件循环线程（客户端连接握手需要服务器轮询响应）
    pthread_t server_tid;
    pthread_create(&server_tid, NULL, server_loop, server);

    // 创建客户端
    ssn_client_t *client = ssn_client_create();
    if (!client) {
        printf("Failed to create client\n");
        return 1;
    }

    // 连接服务器（同步，最多等待 5 秒）
    struct timespec timeout = { .tv_sec = 5, .tv_nsec = 0 };
    if (!ssn_client_connect(client, "unix:///tmp/my_server", &timeout)) {
        printf("Failed to connect to server\n");
        ssn_client_close(client);
        return 1;
    }

    // 发送消息（消息需携带目标 URL）
    ssn_url_ref_t url = { .url = "/hello", .url_len = 6 };
    ssn_data_ref_t data = { .data = "Hello, SSN!", .length = 11 };
    if (ssn_client_message(client, &url, &data) < 0) {
        printf("Failed to send message\n");
    }

    // 等待服务器处理
    sleep(1);

    // 清理资源
    ssn_client_close(client);
    pthread_join(server_tid, NULL);
    ssn_server_destroy(server);

    return 0;
}
```

## 3. 核心概念

### 3.1 传输协议

SSN 支持三种传输协议：

- **Unix Socket**（`unix://`）：适用于本地进程间通信，速度最快
- **TCP**（`tcp://`）：适用于网络通信，提供可靠的面向连接传输
- **UDP**（`udp://`）：适用于实时性要求高的场景，提供无连接的尽力而为传输

地址格式统一为 `协议://地址` 形式：

| 协议 | 地址格式 | 示例 |
|------|----------|------|
| Unix Socket | `unix:///path/to/socket` | `unix:///tmp/my_server` |
| TCP | `tcp://host:port` | `tcp://127.0.0.1:8080` |
| UDP | `udp://host:port` | `udp://127.0.0.1:9090` |

注意：`unix://` 前缀是必需的（`ssn_address_parse` 要求地址含 `://`）。仅服务端创建时（`ssn_server_create`/`ssn_server_create_with_options`）对不带前缀的裸路径会自动补全 `unix://`；客户端连接地址请始终使用完整的 `协议://` 格式。

### 3.2 节点抽象

节点（`ssn_node_t`）是 SSN 提供的高级抽象，它封装了客户端和服务器能力，支持：

- 同时作为客户端和服务器
- 节点间通信（`ssn_node_send_to_peer`、`ssn_node_rpc_call`、`ssn_node_subscribe`）
- 节点生命周期管理（create / start / stop / destroy）
- 节点状态与统计查询

### 3.3 通信模式

SSN 支持三种通信模式：

- **消息传递**：直接向指定目标发送消息（`ssn_client_message` / `ssn_server_message`）
- **RPC**：远程过程调用，请求-响应模式（`ssn_client_call` / `ssn_server_add_method`）
- **发布/订阅**：基于主题的消息发布和订阅（`ssn_server_publish` / `ssn_client_subscribe`）

### 3.4 数据与 URL 引用

消息的 URL 与负载通过引用结构传递，**指针指向的内容仅在回调返回前有效**，需要长期使用时必须在回调内复制。`url_len` 与 `length` 均为 **strlen 语义（不含 NUL 终止符）**，与代码 `ssn_get_url`/`ssn_get_data` 的解析行为一致；本指南示例中的字面量均取对应字符串的 strlen 值：

```c
typedef struct {
    char *url;              // URL 字符串
    size_t url_len;         // URL 长度（strlen 语义，不含 NUL 终止符）
} ssn_url_ref_t;

typedef struct {
    void *data;             // 数据指针
    size_t length;          // 数据长度（strlen 语义，不含 NUL 终止符）
} ssn_data_ref_t;
```

## 4. 核心 API

### 4.1 版本 API（version/ssn_version.h）


### 4.2 客户端 API（ssn_client.h）

```c

                        const struct timespec *timeout);

// 断开连接（断开后可再次调用 ssn_client_connect 重新连接）
bool ssn_client_disconnect(ssn_client_t *client);

// 查询是否已连接
bool ssn_client_is_connect(ssn_client_t *client);

// 设置发送超时（毫秒，0 表示使用默认超时 IPC_DEF_SEND_TIMEOUT）
bool ssn_client_send_timeout(ssn_client_t *client, const int timeout_ms);

// 事件循环（返回 0 表示成功）
int ssn_client_poll(ssn_client_t *client, uint64_t timeout_ms);
void ssn_client_run(ssn_client_t *client);

// 发送消息（消息类型，返回 <0 表示失败）
int ssn_client_message(ssn_client_t *client,
                       const ssn_url_ref_t *url, const ssn_data_ref_t *data);

// RPC 调用（返回 <0 表示发送失败；0 表示请求已发出）
int ssn_client_call(ssn_client_t *client,
                    const ssn_url_ref_t *url, const ssn_data_ref_t *data,
                    ssn_client_rpcreply_handler_t callback, void *arg,
                    uint64_t timeout_ms);

// 订阅主题（返回 true 表示订阅成功）
bool ssn_client_subscribe(ssn_client_t *client, const ssn_url_ref_t *url,
                          ssn_client_msg_handler_t callback, void *arg,
                          uint64_t timeout_ms);

// 取消订阅
bool ssn_client_unsubscribe(ssn_client_t *client,
                            const ssn_url_ref_t *url, uint64_t timeout_ms);

// 设置 MESSAGE 类型处理器（用于错误/未处理消息；
// v2.1.0 起同时作为订阅消息的 onsub 回调）
void ssn_client_set_on_message(ssn_client_t *client,
                               ssn_client_msg_handler_t callback, void *arg);

// 设置 PUBLISH 类型处理器（通常由 ssn_client_auto 内部设置，用户一般不直接调用）
void ssn_client_set_on_publish(ssn_client_t *client,
                               ssn_client_msg_handler_t callback, void *arg);

// 关闭客户端
void ssn_client_close(ssn_client_t *client);
```

### 4.5 自动重连客户端 API（ssn_cliauto.h）

`ssn_client_auto` 是客户端扩展模块，自动处理连接、断线重连、订阅与事件循环，用户只需关注业务本身。除 `ssn_client_auto_handle` 外的函数**不允许在客户端事件循环线程上下文（如 RPC 回调、订阅消息回调）中调用**。

```c
// 创建/删除
ssn_client_auto_t *ssn_client_auto_create(void);
void ssn_client_auto_delete(ssn_client_auto_t *cliauto);

// 设置连接状态回调（connect=true 表示连接并订阅成功）
bool ssn_client_auto_setup(ssn_client_auto_t *cliauto,
                           ssn_client_conn_func_t onconn, void *arg);

// 启动（server 可为 ip:port 或服务主机名；
// urls/url_cnt 为建链后要订阅的 URL 列表；
// keepalive 为 ping 间隔（毫秒，最小 50ms），
// conn_timeout 为连接超时（毫秒，最小 20ms），
// reconn_delay 为重连等待时间（毫秒，最小 20ms））
bool ssn_client_auto_start(ssn_client_auto_t *cliauto, const char *server,
                           char *const urls[], int url_cnt,
                           unsigned int keepalive, unsigned int conn_timeout,
                           unsigned int reconn_delay);

// 停止（ssn_client_auto_start 与 ssn_client_auto_stop 必须成对顺序调用）
bool ssn_client_auto_stop(ssn_client_auto_t *cliauto);

// 获取通信用客户端句柄（仅用于通信，不能做关闭连接等状态操作）
ssn_client_t *ssn_client_auto_handle(ssn_client_auto_t *cliauto);
```

## 5. 使用示例

以下示例代码与 `examples/` 目录下同名示例逻辑一致（完整可运行版本见 `examples/basic/` 与 `examples/advanced/`）。

### 5.1 基础通信（hello）

**客户端代码**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_client.h"

static void message_handler(ssn_client_t *client, ssn_url_ref_t *url,
                            ssn_data_ref_t *data, void *arg)
{
    (void)client; (void)url; (void)arg;
    printf("Received message: %.*s\n",
           (int)data->length, (const char *)data->data);
}

int main(void)
{
    // 创建客户端
    ssn_client_t *client = ssn_client_create();
    if (!client) return 1;

    // 设置消息回调（同时作为订阅消息回调）
    ssn_client_set_on_message(client, message_handler, NULL);

    // 连接服务器
    struct timespec timeout = { .tv_sec = 5, .tv_nsec = 0 };
    if (!ssn_client_connect(client, "unix:///tmp/my_server", &timeout)) {
        ssn_client_close(client);
        return 1;
    }

    // 发送消息
    ssn_url_ref_t url = { .url = "/hello", .url_len = 6 };
    ssn_data_ref_t data = { .data = "Hello from client!", .length = 18 };
    if (ssn_client_message(client, &url, &data) < 0) {
        printf("Failed to send message\n");
    }

    // 等待响应
    sleep(2);

    // 清理
    ssn_client_close(client);
    return 0;
}
```

**服务器代码**：

```c
#include <stdio.h>
#include <unistd.h>
#include "ssn_server.h"

// 消息回调（服务器消息处理器）
static void message_handler(ssn_server_t *server, ssn_peer_id_t id,
                            ssn_url_ref_t *url, ssn_data_ref_t *data, void *arg)
{
    (void)url; (void)arg;
    printf("Received message from client %u: %.*s\n",
           id, (int)data->length, (const char *)data->data);

    // 回复客户端
    ssn_url_ref_t reply_url = { .url = "/hello", .url_len = 6 };
    ssn_data_ref_t reply = { .data = "Hello from server!", .length = 18 };
    ssn_server_message(server, id, &reply_url, &reply);
}

int main(void)
{
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/my_server");
    if (!server) return 1;

    // 设置消息回调
    ssn_server_set_message_handler(server, message_handler, NULL);

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 运行服务器（事件循环：poll 驱动连接握手与消息分发）
    printf("Server running. Press Ctrl+C to stop.\n");
    while (1) {
        ssn_server_poll(server, 1000);
    }

    // 清理（实际不会执行到）
    ssn_server_destroy(server);
    return 0;
}
```

### 5.2 RPC 调用

**服务器代码**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_server.h"
#include "ssn_error.h"

// RPC 方法回调：入参为请求数据，通过 ssn_server_response 返回结果
static void add_handler(ssn_server_t *server, ssn_peer_id_t id,
                        ssn_header_t *ipc_hdr, ssn_url_ref_t *url,
                        ssn_data_ref_t *data, void *arg)
{
    (void)url; (void)arg;

    // 解析参数
    int a = 0, b = 0;
    sscanf((const char *)data->data, "{\"a\": %d, \"b\": %d}", &a, &b);

    // 计算结果
    char response[32];
    snprintf(response, sizeof(response), "%d", a + b);

    ssn_data_ref_t resp_data = {
        .data = response,
        .length = strlen(response)
    };

    // 发送响应（status=SSN_ECODE_SUCCESS，seqno 取请求头）
    ssn_server_response(server, id, SSN_ECODE_SUCCESS,
                        ssn_get_seqno(ipc_hdr), &resp_data);
}

int main(void)
{
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/rpc_server");
    if (!server) return 1;

    // 注册 RPC 方法
    ssn_url_ref_t url = { .url = "/math/add", .url_len = 9 };
    ssn_server_add_method(server, &url, add_handler, NULL);

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 运行服务器（事件循环：poll 驱动连接握手与消息分发）
    printf("RPC server running. Press Ctrl+C to stop.\n");
    while (1) {
        ssn_server_poll(server, 1000);
    }
    ssn_server_destroy(server);
    return 0;
}
```

**客户端代码**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_client.h"
#include "ssn_error.h"

// 应答标志：由 poll 驱动的事件循环在回调中置位，主循环据此退出
static volatile int g_reply_received = 0;

// RPC 响应回调：ipc_hdr 为 NULL 表示服务器未响应（如超时）
static void rpc_reply_handler(ssn_client_t *client, ssn_header_t *ipc_hdr,
                              ssn_data_ref_t *data, void *arg)
{
    (void)client; (void)arg;
    g_reply_received = 1;

    if (ipc_hdr == NULL) {
        printf("RPC call failed: server not responding\n");
        return;
    }

    uint32_t status = ssn_get_status(ipc_hdr);
    if (status != SSN_ECODE_SUCCESS) {
        printf("RPC call failed, status: 0x%08x (%s)\n",
               status, ssn_ecode_message(status));
        return;
    }

    printf("RPC result: %.*s\n",
           (int)data->length, (const char *)data->data);
}

int main(void)
{
    // 创建客户端
    ssn_client_t *client = ssn_client_create();
    if (!client) return 1;

    // 连接服务器
    struct timespec timeout = { .tv_sec = 5, .tv_nsec = 0 };
    if (!ssn_client_connect(client, "unix:///tmp/rpc_server", &timeout)) {
        ssn_client_close(client);
        return 1;
    }

    // 构建 RPC 请求
    ssn_url_ref_t url = { .url = "/math/add", .url_len = 9 };
    ssn_data_ref_t data = { .data = "{\"a\": 5, \"b\": 3}", .length = 16 };

    // 发起 RPC 调用（timeout_ms = 5000 毫秒）
    if (ssn_client_call(client, &url, &data, rpc_reply_handler, NULL, 5000) < 0) {
        printf("Failed to send RPC call\n");
        ssn_client_close(client);
        return 1;
    }

    // 等待响应（事件循环：应答回调由 poll 驱动，轮询至回调置位或超时）
    for (int i = 0; i < 50 && !g_reply_received; i++) {
        ssn_client_poll(client, 100);
    }

    // 清理
    ssn_client_close(client);
    return 0;
}
```

### 5.3 发布/订阅

**发布者代码**（服务器端发布）：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_server.h"

int main(void)
{
    // 创建服务器
    ssn_server_t *server = ssn_server_create("unix:///tmp/pubsub_server");
    if (!server) return 1;

    // 启动服务器
    if (!ssn_server_start(server)) {
        ssn_server_destroy(server);
        return 1;
    }

    // 发布消息（事件循环：先 poll 处理订阅握手，再发布，再 poll 分发）
    ssn_url_ref_t url = { .url = "/news", .url_len = 5 };
    for (int i = 0; i < 5; i++) {
        ssn_server_poll(server, 100);
        char message[64];
        snprintf(message, sizeof(message), "News update %d", i + 1);
        ssn_data_ref_t data = {
            .data = message,
            .length = strlen(message)
        };
        ssn_server_publish(server, &url, &data);
        printf("Published: %s\n", message);
        ssn_server_poll(server, 100);
        sleep(1);
    }

    // 清理
    ssn_server_destroy(server);
    return 0;
}
```

**订阅者代码**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_client.h"

// 订阅消息回调（收到发布的消息时被调用；url->url 非 NUL 结尾，用 %.*s 打印）
static void message_handler(ssn_client_t *client, ssn_url_ref_t *url,
                            ssn_data_ref_t *data, void *arg)
{
    (void)client; (void)arg;
    printf("Received on %.*s: %.*s\n",
           (int)url->url_len, url->url,
           (int)data->length, (const char *)data->data);
}

int main(void)
{
    // 创建客户端
    ssn_client_t *client = ssn_client_create();
    if (!client) return 1;

    // 连接服务器
    struct timespec timeout = { .tv_sec = 5, .tv_nsec = 0 };
    if (!ssn_client_connect(client, "unix:///tmp/pubsub_server", &timeout)) {
        ssn_client_close(client);
        return 1;
    }

    // 订阅主题
    ssn_url_ref_t url = { .url = "/news", .url_len = 5 };
    if (!ssn_client_subscribe(client, &url, message_handler, NULL, 5000)) {
        printf("Failed to subscribe\n");
        ssn_client_close(client);
        return 1;
    }

    // 轮询接收消息
    printf("Subscribed to /news. Press Ctrl+C to stop.\n");
    for (int i = 0; i < 10; i++) {
        ssn_client_poll(client, 1000);
    }

    // 取消订阅
    ssn_client_unsubscribe(client, &url, 5000);

    // 清理
    ssn_client_close(client);
    return 0;
}
```

### 5.4 节点通信

节点 A 与节点 B 各自作为独立的节点运行，通过 `peer_address`（`host:port`）互连。节点 B 订阅节点 A 的 `/hello` 主题，节点 A 发布消息。

**节点 A（发布端）**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "node/ssn_node.h"

int main(void)
{
    // 配置节点
    ssn_node_config_t config = {
        .node_type = "example",
        .node_name = "node_a",
        .listen_address = "127.0.0.1",
        .listen_port = 8890,
        .capabilities = SSN_NODE_CAP_RPC | SSN_NODE_CAP_PUBSUB |
                        SSN_NODE_CAP_SERVER | SSN_NODE_CAP_CLIENT
    };

    // 创建并启动节点
    ssn_node_t *node = ssn_node_create(&config);
    if (!node) return 1;
    if (!ssn_node_start(node)) {
        ssn_node_destroy(node);
        return 1;
    }

    // 运行一段时间（事件循环：节点 A 作为服务端必须 poll 才能接受订阅连接与握手）
    printf("Node A running...\n");
    for (int i = 0; i < 5; i++) {
        ssn_node_poll(node, 100);
        /* 订阅建立后周期发布（首轮 poll 先处理订阅握手，避免消息先于订阅发出） */
        if (i >= 1) {
            ssn_node_publish(node, &url, &data);
        }
    }

    // 停止并销毁节点
    ssn_node_stop(node);
    ssn_node_destroy(node);
    return 0;
}
```

**节点 B（订阅端）**：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "node/ssn_node.h"

// 订阅消息回调（url->url 非 NUL 结尾，用 %.*s 打印）
static void message_handler(ssn_client_t *client, ssn_url_ref_t *url,
                            ssn_data_ref_t *data, void *arg)
{
    (void)client; (void)arg;
    printf("Node B received on %.*s: %.*s\n",
           (int)url->url_len, url->url,
           (int)data->length, (const char *)data->data);
}

int main(void)
{
    // 配置节点
    ssn_node_config_t config = {
        .node_type = "example",
        .node_name = "node_b",
        .listen_address = "127.0.0.1",
        .listen_port = 8891,
        .capabilities = SSN_NODE_CAP_RPC | SSN_NODE_CAP_PUBSUB |
                        SSN_NODE_CAP_SERVER | SSN_NODE_CAP_CLIENT
    };

    // 创建并启动节点
    ssn_node_t *node = ssn_node_create(&config);
    if (!node) return 1;
    if (!ssn_node_start(node)) {
        ssn_node_destroy(node);
        return 1;
    }

    // 订阅节点 A（peer_address 指定对端地址）
    ssn_url_ref_t url = { .url = "/hello", .url_len = 6 };
    if (!ssn_node_subscribe(node, "tcp://127.0.0.1:8890", &url,
                            message_handler, NULL, 5000)) {
        printf("Failed to subscribe\n");
        ssn_node_stop(node);
        ssn_node_destroy(node);
        return 1;
    }

    // 轮询接收消息
    printf("Node B running...\n");
    for (int i = 0; i < 5; i++) {
        ssn_node_poll(node, 1000);
    }

    // 停止并销毁节点
    ssn_node_stop(node);
    ssn_node_destroy(node);
    return 0;
}
```

节点之间还可以通过 `ssn_node_send_to_peer(node, "tcp://127.0.0.1:8890", &url, &data)` 定向发送消息，或通过 `ssn_node_rpc_call` 发起节点间 RPC（签名与客户端 `ssn_client_call` 类似，多一个 `peer_address` 参数）。

### 5.5 错误处理

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include "ssn_client.h"
#include "ssn_error.h"

// RPC 响应回调：检查状态码并输出错误描述
static void rpc_reply_handler(ssn_client_t *client, ssn_header_t *ipc_hdr,
                              ssn_data_ref_t *data, void *arg)
{
    (void)client; (void)arg;

    if (ipc_hdr == NULL) {
        // 服务器未响应（超时）
        printf("RPC failed: %s\n", ssn_ecode_message(SSN_ECODE_TIMEOUT));
        return;
    }

    uint32_t status = ssn_get_status(ipc_hdr);
    if (status != SSN_ECODE_SUCCESS) {
        printf("RPC failed: %s (0x%08x)\n", ssn_ecode_message(status), status);
        return;
    }

    printf("RPC result: %.*s\n",
           (int)data->length, (const char *)data->data);
}

int main(void)
{
    ssn_client_t *client = ssn_client_create();
    if (!client) return 1;

    // 场景 1：连接不存在的服务器（connect 返回 false）
    struct timespec timeout = { .tv_sec = 2, .tv_nsec = 0 };
    if (!ssn_client_connect(client, "unix:///tmp/no_such_server", &timeout)) {
        printf("Connect failed: %s\n", ssn_ecode_message(SSN_ECODE_NET_CONNECT));
        ssn_client_close(client);
        return 1;
    }

    // 场景 2：调用未注册的方法（服务器返回错误状态码）
    ssn_url_ref_t url = { .url = "/no_such_method", .url_len = 15 };
    ssn_data_ref_t data = { .data = "test", .length = 4 };
    if (ssn_client_call(client, &url, &data, rpc_reply_handler, NULL, 2000) < 0) {
        printf("Failed to send RPC call\n");
    }

    // 等待应答回调（事件循环：应答由 poll 驱动）
    for (int i = 0; i < 20; i++) {
        ssn_client_poll(client, 100);
    }
    ssn_client_close(client);
    return 0;
}
```

## 6. 错误处理

### 6.1 错误码（SSN_ECODE_*）

错误码类型为 `ssn_ecode_t`（uint32_t），由 `SSN_ECODE_MAKE(category, subcategory, code)` 宏组合生成：高 8 位为类别，中间 8 位为子类别，低 16 位为具体错误码。完整定义见 `src/ssn_error.h`：

| 类别 | 错误码 | 数值 | 说明 |
|------|--------|------|------|
| 通用 | `SSN_ECODE_SUCCESS` | 0x00000000 | 成功 |
| 通用 | `SSN_ECODE_INVALID_ARGS` | 0x00000001 | 无效参数 |
| 通用 | `SSN_ECODE_NOT_FOUND` | 0x00000002 | 未找到 |
| 通用 | `SSN_ECODE_TIMEOUT` | 0x00000003 | 超时 |
| 通用 | `SSN_ECODE_INTERNAL` | 0x00000004 | 内部错误 |
| 网络 | `SSN_ECODE_NET_CONNECT` | 0x01000001 | 连接失败 |
| 网络 | `SSN_ECODE_NET_DISCONNECT` | 0x01000002 | 连接断开 |
| 网络 | `SSN_ECODE_NET_READ` | 0x01000003 | 读取失败 |
| 网络 | `SSN_ECODE_NET_WRITE` | 0x01000004 | 写入失败 |
| 服务 | `SSN_ECODE_SERVICE_NOT_FOUND` | 0x02000001 | 服务未找到 |
| 服务 | `SSN_ECODE_SERVICE_BUSY` | 0x02000002 | 服务繁忙 |
| 服务 | `SSN_ECODE_SERVICE_ERROR` | 0x02000003 | 服务错误 |
| 资源 | `SSN_ECODE_OUT_OF_MEMORY` | 0x03000001 | 内存不足 |
| 资源 | `SSN_ECODE_RESOURCE_LIMIT` | 0x03000002 | 资源限制 |
| 安全 | `SSN_ECODE_AUTH_FAILED` | 0x04000001 | 认证失败 |
| 安全 | `SSN_ECODE_ACCESS_DENIED` | 0x04000002 | 访问拒绝 |
| 序列化 | `SSN_ECODE_SERIALIZE_FAILED` | 0x05000001 | 序列化失败 |
| 序列化 | `SSN_ECODE_DESERIALIZE_FAILED` | 0x05000002 | 反序列化失败 |

### 6.2 错误处理函数（ssn_error.h）

```c
const char *ssn_ecode_message(ssn_ecode_t error);      // 错误码 → 错误描述
uint8_t     ssn_ecode_category(ssn_ecode_t error);     // 获取错误类别
uint8_t     ssn_ecode_subcategory(ssn_ecode_t error);  // 获取错误子类别
uint16_t    ssn_ecode_code(ssn_ecode_t error);         // 获取具体错误码

// 记录错误日志（带文件名/行号/函数名/格式化信息）
void ssn_handle_error(ssn_ecode_t error, const char *file, int line,
                      const char *func, const char *format, ...);
```

### 6.3 错误处理最佳实践

- 检查所有返回 `bool` / `int` 的 API 返回值：`connect`、`start`、`subscribe`、`call`、`message` 等
- RPC 响应回调中先判断 `ipc_hdr` 是否为 NULL（服务器未响应），再用 `ssn_get_status(ipc_hdr)` 与 `SSN_ECODE_SUCCESS` 比较
- 使用 `ssn_ecode_message()` 将错误码转换为可读描述
- 用 `ssn_handle_error()` 在错误路径记录日志，便于定位

## 7. 性能优化

### 7.1 连接管理

- **长连接**：使用长连接减少连接建立和销毁的开销
- **心跳机制**：通过 `ssn_client_auto` 的 keepalive 参数定期发送心跳保持连接活跃（最小 50ms）
- **自动重连**：网络抖动场景使用 `ssn_client_auto` 的断线自动重连与订阅恢复

### 7.2 消息处理

- **批量发送**：将多个小消息合并为一个大消息发送
- **异步处理**：使用回调 + 事件循环（`poll`/`run`）模型避免阻塞主线程
- **单线程事件循环**：库为单线程事件循环模型设计，跨线程使用客户端/服务器对象需自行加锁同步

### 7.3 内存管理

- **引用生命周期**：回调中的 `url`/`data` 指针在回调返回后即失效，需要长期保存的数据必须在回调内复制
- **数据包上限**：单包最大 128 KiB（`SSN_MAX_PACKET_SIZE`，131072 字节），超过该大小的数据需在应用层分片传输

## 8. 常见问题

### 8.1 连接失败

**问题**：客户端无法连接到服务器

**解决方案**：
- 检查服务器是否正在运行
- 检查地址格式是否正确（例如：`unix:///tmp/server`）
- 检查权限是否正确
- 检查防火墙设置

### 8.2 RPC 调用超时

**问题**：RPC 调用超时（响应回调中 `ipc_hdr` 为 NULL）

**解决方案**：
- 检查网络连接是否稳定
- 增加 `ssn_client_call` 的 `timeout_ms`
- 检查服务器是否正常处理请求
- 检查请求数据是否正确

### 8.3 消息丢失

**问题**：发布的消息没有被订阅者收到

**解决方案**：
- 检查订阅是否成功（`ssn_client_subscribe` 返回 false 时排查）
- 检查主题路径是否正确
- 检查网络连接是否稳定
- 对于关键消息，考虑使用 RPC 而不是发布/订阅

### 8.4 性能问题

**问题**：通信性能不达标

**解决方案**：
- 使用 Unix Socket 进行本地通信
- 优化消息大小（单包不超过 128 KiB）
- 使用批量发送
- 调整缓冲区大小

## 9. 进阶功能

### 9.1 多线程通信

SSN 基于单线程事件循环模型设计：**建议在同一线程中创建、轮询和关闭客户端/服务器对象**，发送类 API（如 `ssn_client_message`、`ssn_client_call`）可在其他线程调用，但跨线程访问同一对象时需自行加锁同步：

```c
// 在主线程中创建客户端并进入事件循环
ssn_client_t *client = ssn_client_create();

// 在子线程中发送消息（需自行保证 client 的线程安全）
void *send_thread(void *arg) {
    ssn_client_t *client = (ssn_client_t *)arg;
    // 发送消息...
    return NULL;
}

pthread_t thread;
pthread_create(&thread, NULL, send_thread, client);
```

### 9.2 传输协议选择

根据不同的场景选择合适的传输协议：

- **Unix Socket**：本地进程间通信，速度最快
- **TCP**：网络通信，提供可靠传输
- **UDP**：实时性要求高的场景，如音频、视频流

### 9.3 安全通信

TLS/DTLS 加密传输尚未实现，当前版本可以在应用层实现加密：发送前加密负载写入 `ssn_data_ref_t`，接收后在回调内解密。
