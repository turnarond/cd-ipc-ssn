## 已知边界与风险

- 主要支持 POSIX/Linux；Windows 建议使用 WSL 或 CMake 工具链验证。
- UDP 服务端握手、节点发现和 QoS 尚未形成可用产品能力。
- C++ 服务端当前以 TCP 为主；`SsnClient` 仅支持单个进行中的请求。
- CI 尚未设置覆盖率门禁。长期运行仍需持续检查内存、线程、句柄和套接字泄漏。

## 维护者发布操作

确认最终分支已合并、工作区干净且 HEAD 正是待发布内容后，由维护者创建附注 tag：

```bash
git tag -a v2.5.1 -m "release: v2.5.1"
git push origin v2.5.1
```

执行后使用 `git show --no-patch v2.5.1` 核对 tag 的实际指向，并在发布记录中保存提交 SHA 与验证结果。
