## 3. 模块详细设计

### 3.1 协议层模块 (Protocol Layer)

#### 3.1.1 协议类型定义

```c
// 协议类型
typedef enum {
    SSN_PROTOCOL_RPC = 0,      // RPC请求-应答协议
    SSN_PROTOCOL_PUBSUB,       // 发布-订阅协议
    SSN_PROTOCOL_MSG            // 点对点消息协议
} ssn_protocol_type_t;

// 角色类型
typedef enum {
    SSN_ROLE_REQ = 0,           // RPC请求端（客户端）
    SSN_ROLE_REP,               // RPC应答端（服务端）
    SSN_ROLE_SEND,              // 消息发送端（客户端）
    SSN_ROLE_RECV,              // 消息接收端（服务端）
    SSN_ROLE_PUB,               // 发布端（服务端）
    SSN_ROLE_SUB                // 订阅端（客户端）
} ssn_role_t;
```

#### 3.1.2 协议上下文基类

```c
// 协议上下文基类
typedef struct ssn_protocol_ctx {
    ssn_protocol_type_t type;      // 协议类型
    ssn_role_t role;                // 角色类型
    ssn_transport_t *transport;     // 底层传输层
    void (*destroy)(struct ssn_protocol_ctx *ctx);  // 销毁函数
    void *user_data;                // 用户数据
} ssn_protocol_ctx_t;
```

#### 3.1.3 模块职责

| 模块 | 职责 | 核心数据结构 |
|------|------|-------------|
| `ssn_rpc` | RPC请求管理、序列号生成、待处理请求池、方法注册表 | `rpc_pending_entry_t` |
| `ssn_pubsub` | 订阅者管理、主题匹配、消息分发 | `pubsub_subscription_t` |
| `ssn_msg` | 消息队列管理、消息分发 | `msg_queue_entry_t` |

### 3.2 客户端/服务端层 (Client/Server Layer)

#### 3.2.1 客户端结构 (重构后)

```c
struct ssn_client {
    /* 传输层 */
    ssn_transport_t *transport;

    /* 协议层实例 */
    ssn_rpc_req_t *rpc_req;           /* RPC请求端 */
    ssn_pubsub_sub_t *pubsub_sub;     /* 订阅端 */
    ssn_msg_send_t *msg_send;         /* 消息发送端 */

    /* 连接管理 */
    bool valid;
    bool connected;
    ipc_event_pair_t *evtfd;
    ipc_mutex_t *lock;
    int ref_count;

    /* 回调函数 */
    ssn_client_msg_handler_t onsub;
    void *sub_arg;
    ssn_client_msg_handler_t onmsg;
    void *msg_arg;
    ssn_client_rpcreply_handler_t onrpc;
    void *rpc_arg;

    /* 全局链表 */
    ssn_client_t *next;
    ssn_client_t *prev;
};
```

#### 3.2.2 服务端结构 (重构后)

```c
struct ssn_server {
    /* 传输层 */
    ssn_transport_t *transport;

    /* 协议层实例 */
    ssn_rpc_rep_t *rpc_rep;           /* RPC应答端 */
    ssn_pubsub_pub_t *pubsub_pub;    /* 发布端 */
    ssn_msg_recv_t *msg_recv;        /* 消息接收端 */

    /* 服务器状态 */
    bool valid;
    bool running;
    char *server_info;

    /* 客户端管理 */
    ssn_server_client_t *clients;
    int client_count;
    ipc_mutex_t *client_lock;

    /* 回调函数 */
    ssn_on_connect_t onconn;
    void *conn_arg;
    ssn_server_msg_handler_t onmsg;
    void *msg_arg;
};
```

#### 3.2.3 模块职责

| 模块 | 职责 | 与协议层关系 |
|------|------|-------------|
| `ssn_client` | 连接生命周期、事件循环、消息路由、引用计数 | 调用协议层模块 |
| `ssn_server` | 监听管理、客户端连接、事件循环、消息路由 | 调用协议层模块 |
| `ssn_cliauto` | 自动重连、自动订阅、状态机 | 通过客户端API调用协议层 |

#### 3.3.1 节点结构设计

```c
struct ssn_node {
    /* 配置信息 */
    ssn_node_config_t config;
    char node_id[64];

    /* 状态信息 */
    ssn_node_state_t state;
    uint32_t ref_count;
    time_t start_time;

    /* 网络资源 */
    ssn_transport_t *transport;          /* 主传输层 */
    ipc_event_loop_t *event_loop;
    ssn_connection_pool_t *conn_pool;

    /* 协议层实例（节点级别） */
    ssn_rpc_rep_t *rpc_server;           /* RPC应答端 */
    ssn_pubsub_pub_t *pubsub_pub;        /* 发布端 */

    /* 管理模块 */
    ssn_service_registry_t *services;    /* 服务注册表 */
    ssn_subscription_table_t *topics;    /* 订阅表 */

    /* 回调函数 */
    ssn_node_message_handler_t on_message;
    ssn_node_connect_handler_t on_connect;

    /* 同步机制 */
    ipc_mutex_t *lock;
};

typedef enum {

    SSN_NODE_STATE_CREATED,
    SSN_NODE_STATE_STARTING,
    SSN_NODE_STATE_ACTIVE,
```

## 5. 接口设计

## 8. 设计原则总结

### 8.1 核心原则

1. **分层职责清晰**
   - 协议层：协议编解码、序列号管理、方法注册
   - 传输层：网络通信、地址解析
   - 客户端/服务端：连接管理、事件循环
   - 节点层：服务管理、节点发现

2. **模块独立可测试**
   - 每个模块有明确的接口
   - 模块间通过接口通信
   - 便于单元测试

3. **向后兼容**
   - 现有API保持不变
   - 内部实现重构对用户透明

4. **性能优先**
   - 减少不必要的数据拷贝
   - 合理使用内存池
   - 高效的事件处理

### 8.2 扩展性设计

1. **协议扩展**：新增协议只需实现协议层接口
2. **传输层扩展**：新增传输协议只需实现传输层接口
3. **节点层扩展**：可插拔的服务发现、安全机制

## 9. 总结

本架构设计文档整合了SSN的完整架构：

1. **已完成**：协议层模块化拆分和实现
2. **进行中**：客户端/服务端重构
3. **待实现**：节点抽象层

整体架构采用分层设计，职责清晰，便于维护和扩展。协议层与传输层完全解耦，提供了灵活的组合方式。
